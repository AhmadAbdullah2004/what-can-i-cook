# What Can I Cook?

A recipe discovery website that helps users find recipes based on the ingredients they already have.

## Live Demo

[View Live Website](https://what-can-i-cook-v1.netlify.app/)

## Features

- Choose ingredients from your fridge
- Find matching recipes
- Browse popular recipes
- View detailed cooking instructions
- Responsive design for desktop and mobile

## Technologies

- HTML
- CSS
- JavaScript
- JSON

## Project

This project was built as a front-end project to practice HTML, CSS, and JavaScript.
